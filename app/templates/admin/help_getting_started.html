What This System Does

Weighbridge Web runs day-to-day weighbridge operations from ticket creation through invoicing and print output.

  • Create and complete tickets with weight and product details.
  • Generate invoices from completed tickets and track invoice status.
  • Configure print templates and destinations for Ticket, Invoice, and WTN documents.
  • Capture audit history through print jobs and document records.

Status: this application is still in active development. Some workflows will continue to evolve.

Quick Start Checklist

  1. Go to Admin -> Company and set your company name/address/logo.
  2. Go to Admin -> EWC Codes and import the latest regulatory CSV.
  3. Go to Products and confirm products, units, and pricing are correct.
  4. Go to Admin -> Printing -> Templates and duplicate system templates if you need custom layouts.
  5. Go to Admin -> Printing -> Destinations and confirm one active default destination per document type.
  6. Create a test ticket in Tickets, then preview/print.
  7. Generate a test invoice in Invoices and verify preview/send/PDF.

Daily Workflow (Operators)

  1. Create or open a ticket and record inbound/outbound weights.
  2. Complete the ticket once all required fields are valid.
  3. Use Print Ticket or Preview Ticket as needed.
  4. Generate invoices from eligible completed tickets.
  5. Use Send Invoice, Preview Invoice, or Download PDF.

Administration Workflow

  • Templates: System templates are locked. Duplicate a system template to customise safely.
  • Destinations: Keep one active default per document type so operator actions are one-click.
  • Jobs: Use jobs view to investigate failed sends and retry when appropriate.
  • EWC codes: Re-import CSV whenever list updates are published.

Troubleshooting

  • No EWC codes loaded: import CSV via Admin -> EWC Codes.
  • Print action disabled: check document status and default destination setup.
  • Template rendering error: verify variable names in Template Variables.
