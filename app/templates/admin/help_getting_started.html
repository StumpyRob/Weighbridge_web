What This System Does

Weighbridge Web runs day-to-day weighbridge operations from setup through ticketing, compliance, invoicing, document output, and admin oversight.

  • Run the dashboard in UK time with live date/time visibility, operational totals, and activity panels.
  • Manage customers, vehicles, products, pricing, EWC compliance, and ticket defaults before operators start weighing.
  • Create, complete, preview, print, and email Ticket, Invoice, and WTN documents.
  • Configure print agents, destinations, templates, and job review for local or automated document delivery.
  • Track admin and data changes through the audit log and related document records.

Status: this application is still in active development. Some workflows will continue to evolve.

Quick Start Checklist

  1. Go to Settings -> Company and set your company name/address/logo.
  2. Go to Settings -> EWC Codes and import the latest regulatory CSV.
  3. Go to Products and confirm groups, units, pricing, and waste flags are correct.
  4. Go to Customers and review invoice frequency, payment terms, credit limits, PO rules, and invoice-stop flags.
  5. Go to Vehicles and set default tare, overweight threshold, ticket defaults, and any per-container tares you rely on.
  6. If you print to local printers, go to Settings -> Printing -> Agents and install/pair the required print agents.
  7. Go to Settings -> Printing -> Templates and duplicate system templates if you need custom layouts.
  8. Go to Settings -> Printing -> Destinations and confirm one active default destination per document type.
  9. Create a test ticket in Tickets, check Ticket and WTN preview/print, and confirm any required signatures or destination details render correctly.
  10. Generate a test invoice in Invoices and verify preview, PDF, and email/send behaviour.

Daily Workflow (Operators)

  1. Start from the dashboard; totals and the live clock use UK time, so daily activity should match your operating day.
  2. Create or open a ticket, record inbound/outbound weights, and confirm customer, vehicle, product, and haulier details are correct.
  3. Review account controls before completion, especially credit banners, PO requirements, on-stop flags, and do-not-invoice flags.
  4. Complete the ticket once required waste, destination, and signature details are valid for the workflow you are running.
  5. Use Preview Ticket, Print Ticket, Preview WTN, or related document actions as needed.
  6. Generate invoices from eligible completed tickets, then use Send Invoice, Preview Invoice, or Download PDF.

Customer, Vehicle, and Product Controls

  • Customers: Customer records now cover invoice frequency, payment terms, price overrides, credit summaries, account adjustments, and flags such as ON STOP, NO INVOICE, and PO REQUIRED.
  • Vehicles: Vehicle records can prefill new tickets with default customer, haulier, and driver values, while also storing default tare and per-container tares for repeat traffic.
  • Products: Product setup includes groups, units, nominal codes, EWC defaults, hazardous/final-disposal/used-on-site flags, and default destination or bay selection.

Print Agents, Destinations, Templates, and Jobs

  • Print Agents: Use Settings -> Printing -> Agents to download the site installer, pair local agents, review last seen times, and confirm printer sync status.
  • Destinations: Keep one active default destination per document type so operator actions stay one-click and routed correctly.
  • Templates: System templates are locked. Duplicate a system template before customising it, then use {% if help_show_template_variables %}Template Variables{% else %}Template Variables{% endif %} as the reference for supported fields.
  • Jobs: Use the jobs view to investigate failed sends, inspect rendered output and delivery snapshots, and retry when appropriate.

Audit, Support, and UK Time

  • Audit Log: Use Settings -> Audit Log to review authentication and data-change events across key entities.
  • Company Settings: Company settings also control document email defaults, sign-in email, branding, logo, and theme values used across the workspace.
  • Time zone behaviour: Dashboard time, print timestamps, and admin-facing date/time displays are intended to run in UK time (Europe/London), including seasonal DST changes.
  • Template help: Use {% if help_show_template_variables %}Template Variables{% else %}Template Variables{% endif %} whenever you customise Ticket, Invoice, or WTN layouts.

Troubleshooting

  • No EWC codes loaded: import CSV via Settings -> EWC Codes.
  • Print action disabled or missing: check document status, default destination setup, paired print agents, and recent printer sync state.
  • Ticket or invoice excluded unexpectedly: review customer flags, PO requirements, account balance controls, and document status before retrying.
  • Template rendering error: verify variable names in {% if help_show_template_variables %}Template Variables{% else %}Template Variables{% endif %}.
  • Times look an hour behind: check the server clock/NTP, but note that app-facing operational times are expected to display in UK time with BST/GMT handled automatically.
