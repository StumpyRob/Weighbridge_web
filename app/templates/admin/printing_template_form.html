Template variables

Available in all templates

  • company_name - your company name
  • company_lines - company address lines (list)
  • company.logo_url - company logo URL (if set)
  • payload - document data fields

Accessing document fields

Document fields live under payload.

Examples:

  • {% raw %}{{ payload.reference_no }}{% endraw %}
  • {% raw %}{{ payload.customer_name }}{% endraw %}
  • {% raw %}{{ payload.net_kg }}{% endraw %}

Recommended safe patterns

{% raw %}{{ payload.customer_name or "-" }}{% endraw %}

{% raw %}{% if payload.notes %}
  {{ payload.notes }}
{% endif %}{% endraw %}

{% raw %}{% for line in company_lines %}
  {{ line }}

{% endfor %}{% endraw %}

Template Capabilities & Rules

Templates support standard HTML and CSS for layout and branding.

Allowed images: logo data URIs, local app assets, and inline <img> elements.

External URLs are blocked by default in PDF rendering.

In PDF/Send output: background images and shadows/effects are removed; background colours are preserved.

Browser print note: URL/date/time headers and footers are controlled by browser print settings.

Thermal (80mm text) templates are unaffected.

For watermarks, use a faint positioned <img> (not CSS background-image) if you really need it.

Avoid height: 100vh in templates; use content-based layout for single-page output.
