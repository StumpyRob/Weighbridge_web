Template Variables{{ help(help_text.printing_template_concept, "printing-template-variables-title-help") }}

Use these variables in Ticket, Invoice, and WTN templates.

For WTN signatures, prefer payload.producer_signature_*, payload.carrier_signature_*, and payload.receiver_signature_*. Legacy payload.wtn_signature_* names still map to receiver values for older custom WTN templates.

Available In All Templates
Variable Description Example
company_name Company name from Settings. Your Company Ltd
company_lines Company address lines. ["Line 1", "Town"]
company.logo_url Resolved logo source used by templates (URL or data URI). https://example.com/logo.png
company_logo_url Top-level alias for the resolved company logo source. data:image/png;base64,...
money(value) / fmt_money(value) Formats numbers as money for display. {{ '{{ money(payload.total) }}' }}
fmt_date(value, format) Formats date/datetime values safely for print output. {{ '{{ fmt_date(payload.datetime, "%d/%m/%Y") }}' }}
payload Master print payload. {...}
