What This Application Does

Weighbridge Web is designed for day-to-day site operations. It helps teams:

  • Create and manage inbound/outbound tickets.
  • Maintain customer, vehicle, product, and lookup data.
  • Generate invoices from completed ticket activity.
  • Preview, print, and track print jobs through the admin printing tools.

Status: This platform is still in active development. Some features are evolving.

Get Started Guide

Need setup guidance? Go to Settings -> Help for a full getting-started walkthrough.

  1. Open Lookups and confirm required lookup values exist.
  2. Set up core records in Customers, Vehicles, and Products.
  3. Create your first transaction from Tickets.
  4. Review invoice-ready work in Invoices and generate invoices.
  5. Configure templates and destinations in Settings -> Printing for operational printing.
